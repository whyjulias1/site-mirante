# Mirante Garden Club – landing page

Landing page de vendas do Mirante Garden Club (Pedra Branca, Palhoça/SC), da Luiz Althoff Soluções em Imóveis.

- `index.html`: a página inteira (HTML, CSS e JS).
- `public/img`: fotos e logos.
- `public/fonts`: Montserrat e Poppins.

Os formulários redirecionam para o WhatsApp (48) 99192-6759 com nome, telefone e objetivo preenchidos.

## Rodar localmente

```bash
npm install
npm run dev
```

## Pendências

- Trocar `https://SEU-DOMINIO.com.br/` no `<link rel="canonical">` pelo domínio final.
- Apontar o link "Política de Privacidade" do rodapé para a página real.
